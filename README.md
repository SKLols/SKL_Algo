# SKL_Algo

This repository contains an algorithmic trading scanner project.

## Structure

- `src/` - Python source files for scanners and trading logic
- `output/` - Scan results and data files

## Getting started

1. Install dependencies (if any):
   ```powershell
   pip install -r requirements.txt
   ```

2. Run the scanner scripts from the `src/` folder:
   ```powershell
   python src/vcp_scanner.py
   python src/sepa_scanner.py
   ```

## Notes

- Keep data and results in `output/`.
- Add any configuration or requirements files as needed.
